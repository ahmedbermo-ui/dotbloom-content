# Dotbloom content

Puzzle packs for the Dotbloom Kids app, served by GitHub Pages at
https://ahmedbermo-ui.github.io/dotbloom-content/

Don't edit by hand. Packs are made in the Dotbloom repo (`data/packs`) and published with
`npm run publish-packs` from `Dotbloom/web`. Never delete a pack: people who bought it
download it from here after a reinstall.
